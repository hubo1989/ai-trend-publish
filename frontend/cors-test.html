🔍 CORS 专项测试工具

专门用于诊断跨域请求问题，特别是Docker容器环境下的CORS配置

步骤1: 基础连通性测试

首先测试各种可能的服务器地址的基础连通性

步骤2: OPTIONS 预检请求测试

测试CORS预检请求是否正确响应

步骤3: 实际API请求测试

测试真实的API请求

步骤4: 无认证测试

测试不带认证头的请求（排除认证问题）

步骤5: 简单GET请求测试

测试最简单的GET请求

诊断建议

请按顺序执行上述测试，每个步骤的结果将帮助定位问题所在： 1. 基础连通性失败 → 网络/端口问题 2. OPTIONS请求失败 → CORS预检配置问题 3. API请求失败 → 认证或具体API问题 4. 无认证请求成功 → 认证配置问题 5. GET请求成功 → POST方法或JSON-RPC问题
