# 数据源管理系统演示指南

## 快速演示

### 1. 启动服务

```bash
# 进入前端目录
cd frontend

# 启动前端服务（三种方式任选一种）
./start.sh                    # 推荐：自动检测环境
python3 -m http.server 8080   # Python 3
npm run serve                 # Node.js
```

### 2. 访问应用

在浏览器中打开：http://localhost:8080

### 3. 配置API连接

1. **API地址**: `http://localhost:8000/api/workflow`
2. **API密钥**: 您在环境变量中设置的 `SERVER_API_KEY` 值
3. 点击"测试连接"验证配置

### 4. 功能演示

#### 查看现有数据源
- 页面会自动加载并显示所有数据源
- 统计面板显示总数和分类统计

#### 添加单个数据源
1. 点击"添加数据源"
2. 选择平台：Firecrawl
3. 输入标识符：`https://techcrunch.com`
4. 点击"保存"

#### 批量添加数据源
1. 点击"批量添加"
2. 输入以下内容：
   ```
   firecrawl,https://venturebeat.com
   twitter,@elonmusk
   firecrawl,https://arstechnica.com
   ```
3. 点击"批量添加"

#### 编辑数据源
1. 在列表中找到要编辑的数据源
2. 点击"编辑"按钮
3. 修改标识符或平台类型
4. 点击"保存"

#### 删除数据源
1. 点击要删除的数据源的"删除"按钮
2. 在确认对话框中点击"确认删除"

## 界面截图说明

### 主界面
- **顶部**: 标题和配置面板
- **中间**: 操作按钮和数据源表格
- **底部**: 统计信息面板

### 配置面板
- API地址输入框
- API密钥输入框（密码类型，保护隐私）
- 测试连接按钮

### 数据源表格
- ID列：数据源的唯一标识
- 平台列：显示彩色标签（蓝色=Firecrawl，绿色=Twitter）
- 标识符列：显示URL或用户名，长文本会截断
- 创建时间列：显示数据源创建时间
- 操作列：编辑和删除按钮

### 统计面板
- 总数据源：显示所有数据源数量
- Firecrawl：显示Firecrawl平台数据源数量
- Twitter：显示Twitter平台数据源数量

## 错误处理演示

### 连接错误
- 错误的API地址 → 显示连接失败消息
- 错误的API密钥 → 显示认证失败消息
- 后端服务未启动 → 显示网络错误消息

### 数据验证错误
- 空的平台或标识符 → 显示字段必填提示
- 不支持的平台类型 → 显示平台类型错误
- 重复的数据源 → 显示已存在错误

### 操作错误
- 删除不存在的数据源 → 显示数据源不存在错误
- 更新不存在的数据源 → 显示更新失败错误

## 故障排除

### 常见问题

1. **页面空白**
   - 检查浏览器控制台是否有JavaScript错误
   - 确认所有文件都已正确加载

2. **连接失败**
   - 确认后端服务正在运行
   - 检查API地址和端口
   - 验证API密钥

3. **数据不显示**
   - 确认数据库功能已启用
   - 检查数据库中是否有数据
   - 查看后端日志

4. **样式异常**
   - 清除浏览器缓存
   - 确认CSS文件加载正常
   - 检查浏览器兼容性
